# Alkaa vai aloittaa? — Interactive Finnish Lesson

An interactive Finnish-learning lesson created for **Finnish Daily Dialogues**, an educational project focused on spoken Finnish (*puhekieli*).

The lesson helps learners understand how Finnish verbs express intention and the beginning of an action, with explanations, examples and interactive practice.

## Learning objectives

Learners practise the differences between:

- **alkaa** — to begin / start
- **aloittaa** — to start something
- **aikoa** — to intend / plan to
- **meinata** — to mean / intend to; often used informally
- **ruveta** and **ryhtyä** — to start doing something

The lesson also introduces spoken Finnish forms and the use of the **-maan / -mään** form after verbs expressing the start of an action.

## Features

- Step-by-step lesson navigation
- Finnish examples with English translations
- Grammar explanations and verb comparisons
- Interactive multiple-choice questions and fill-in-the-blank exercises
- Immediate answer feedback and automatic scoring
- Results screen and option to retry the lesson
- Learner feedback to inform future lesson development

## Tech stack

- **HTML** — page structure and learning content
- **CSS** — responsive layout and visual styling
- **Vanilla JavaScript** — navigation, exercise logic, answer validation, scoring and session handling
- **Google Apps Script + Google Sheets** — collection of lesson interaction events and learner feedback
- **AI-assisted development** — used to support implementation and iteration, with human review and editing

## Product analytics

The lesson includes lightweight event tracking to help evaluate how learners interact with the content.

Events include:
- Lesson starts and completions
- Exercise answers and scores
- Session duration
- Learner feedback

This data can support analysis of engagement, completion and perceived difficulty, and help inform future iterations of the learning experience.

## Project context

This lesson is an MVP exploring how Finnish Daily Dialogues can extend its audio content into interactive learning experiences.

The project combines language teaching, content design, hands-on implementation and early-stage product experimentation.
